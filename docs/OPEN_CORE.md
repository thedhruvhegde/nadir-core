# Open Core vs commercial surface

| Public (`nadir-core`) | Private (`nadir` monorepo) |
|-----------------------|----------------------------|
| Pulse / Echo scoring library | Console, auth, tenancy |
| Synthetic generators | Pilot closeout / MTTFF-RE product |
| JSON schemas (draft) | Signed evidence workflows at scale |
| Apache-2.0 contributions | Transit / OEM packaging & sales |

Stars and contributors on Open Core are **distribution**. Paid pilots remain the commercial KPI.
