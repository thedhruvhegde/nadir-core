# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | yes |

## Reporting a vulnerability

Email **founders@nadirai.net** with:

- Description and impact
- Reproduction steps
- Affected commit / release

Please do **not** open a public issue for security-sensitive reports.

## Scope notes

NADIR Core is advisory analytics (shadow-mode scoring). It does not write to vehicle ECUs. Still treat malformed telemetry parsers and deserialization paths carefully.
